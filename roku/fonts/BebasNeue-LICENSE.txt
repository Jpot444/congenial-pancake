BebasNeue.ttf in this directory was produced by unwrapping the WOFF2 the web
player already serves (public/fonts/bebas-neue-latin.woff2) into the TTF
container Roku's Font node requires. The glyph outlines are unmodified; only
the container changed, so both players render the same typeface.
